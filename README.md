# 拼图视觉求解器（Puzzle Vision Solver）

用**计算机视觉 + 真实鼠标事件**自动完成浏览器拼图游戏的「照片 + 纯白混合」模式（5×5）。

**实测成绩：25/25 满格、27~33 步（预算 33）、30~50 秒**，多局复现。

| 证据 | 成绩 |
|---|---|
| `demo_25of25.mp4` | 完整求解录屏：25/25、33 步、用时 00:49 |
| `V8_DONE.png` | 25/25、33 步、用时 00:39 |
| `V8_RUN2.png` | 25/25、27 步、用时 00:49 |

## 1. 环境

- Windows 11，Python 3.11
- 依赖：`opencv-python`、`numpy`、`mss`、`pygetwindow`、`pyautogui`

```powershell
pip install opencv-python numpy mss pygetwindow pyautogui
```

**不需要 YOLO/ultralytics**：最终方案用模板匹配确定「哪块放哪格」，不加载任何模型。

## 2. 运行

1. 打开 Edge，进入拼图站点，窗口**最大化**；
2. **先启动脚本**（它会等待就绪）；
3. 再点「开始这一部分」；
4. 全程不要碰鼠标键盘。

```powershell

```

双击 `run_exam.bat` 等价（内部写死了解释器路径，按自己环境改）。


`demo_25of25.part.mp4` 改名为正式文件，避免中途失败覆盖已有视频。

数据流：

```
截图 → 定位棋盘/参考图 → 切 5×5 分类（白格 / 照片格）
     → 照片格：模板匹配得到「碎片在哪」
     → 调度：外圈→内圈，有锚点才放；没锚点跳过
     → 执行：真实鼠标拖拽 → 进度计数器差分判定 → 失败拖回槽位
```

## 4. 算法要点

**① 为什么不需要分类模型**
站点源码里参考图与拼图碎片是**同一张图**，所以照片格用模板匹配即可唯一确定对应碎片。

**② 模板只取中心 50%**
碎片盒边缘有缺口（深约 22% 短边），缺口露出黑色画布底。整块比对时这些黑像素会把
归一化互相关（NCC）拉低（实测 0.47），只取中心 50% 后为 0.98。

**③ 粗匹配 + 精修**
模板与截图同缩到 0.5 倍做粗搜（快 4 倍），再回到原分辨率在 ±6px 窗口内精修，
实测与全分辨率结果**逐格 0px 偏差**。

**④ 掩膜 + 腐蚀**
棋盘、参考图、顶部 UI 必须涂黑（否则模板会在参考图上匹配到 1.00 分）；
再用「模板尺寸」的核腐蚀，保证模板整体落在允许区内。

**⑤ 吸附判据 = 进度计数器像素差分**
吸附必然使 `进度 N/25` +1 → 文本像素必变（>30 灰度差、>50 个像素）；
不吸附则像素逐点相同。把 OCR 问题降维成二元判据，实测 100% 可靠，仅需 6ms。

**⑥ 锚点约束与死锁**
游戏要求「自身格在外圈，或四邻已放置」才能吸附。若某照片格的四个邻居全是白格，
而白格又被推迟到照片阶段之后，这一格就永远没有锚点——所以按环序整体推进，
没锚点的格子跳过、下一趟再来。

**⑦ 白块只能靠形状**
5 块纯白碎片像素完全相同，区别只在四边的凸/凹/平。测量用**中位数当基准**
（不受盒标定误差影响）+ **极值判凸凹**（V 形剖面的中位数会落在「平」区间）。
形状只有约 70% 可信，所以只用于排序，最终由进度差分裁决。

1. **`find_win()` 误认窗口**：原来用「标题含 puzzle」匹配，而代码目录名 `puzzle_v3`

   会被判成空格 → 报"剩余空格 3"、退出码 3。改为以 `placed`（经进度计数器确认）为准，
   灰度自检仅作提示。

## 8. 已知限制

1. **分辨率绑定**：进度计数器区域与托盘格点常量按 3098×1850 窗口标定，换分辨率需重新标定；
2. **白块形状约 70% 可信**：剩下靠「试放 + 进度差分」兜底，故步数 27~33 而非理论最优 25；
3. **碎片被压住时无解**：游戏偶发把两块碎片叠在一起（托盘只检出 28~29 块），
   被压住的那块在屏幕上完全不可见，对应格无法完成——此时应重开一局；
4. **可能匹配到混淆块**：混淆块中央图案与真碎片几乎相同，模板匹配偶尔会选中它，
   拖上去永远吸不上（引擎只接受该格对应的那一块），表现为某一格反复失败；
5. **只驱动真实鼠标**：不能修改页面状态（会被站点状态守卫判为作弊）；
6. **仅覆盖混合模式 + 5×5**：其它部分与难度未适配。
